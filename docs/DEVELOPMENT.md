# 开发与验证记录

维护者：xuanyide。资源分析、转换工具和运行时实现由Codex完成；实机测试与发布决定由维护者完成。

## 转换原理

从维护者提供的Steam版本提取XP3中的剧本和图像，离线恢复SCN文本、PBD角色层及TLG图片。34份剧本转换为83个场景节点，保留12,172条中文文本、三处选择及结局条件。运行时按需加载小块剧情。镜头、粒子与视频转为静态画面，安装包不含音频。主CG完整显示在上方，人物立绘与下方对白衔接。下一章执行必要状态变化，遇选项即停；TRUE END按原作好、坏结局标志解锁。30个存档键与剧情节点保持兼容。

## 发布版本

- 0.1.3完整版：14,428,657字节，完整角色立绘，圆形亚托莉封面，维护者已确认实机测试通过；历史Release和源码保留。
- 0.1.4轻量版：保留418个亚托莉立绘组合，移除334个其他角色独立立绘文件及5,654处引用；全部背景、CG和人物台词/姓名保留。亚托莉从原始中间图单次缩小至216px高、最多192色。该中间版本未单独公开发布。
- 0.1.5轻量版：10,317,697字节（约10.32MB），修复立绘浮空。5,065处显示框按最终PNG比例放大约8.39%，高度310px，头部top=0保留，下方24px由不透明对白底图遮挡。全部图片字节与0.1.4相同，未再次压缩；多图层保持各自水平中心。维护者于2026-10-13确认实机测试通过并授权发布。

## 验证范围

0.1.5签名、CRC、字体覆盖及12,172条原文对照通过。独立差异检查证明仅立绘显示矩形和版本元数据变化；图片、背景、CG、页面脚本、存档与分支逻辑保持。准确新版在官方Vela模拟器完成全新安装、冷启动、第30栏位新档写入/恢复、原0.1.0第1栏位恢复、点击推进和CG差分。正面、宽幅、背面三种立绘通过真实界面到达，截图像素核对确认下沿接住对白且不漏入文字区域。

滚动、大字号、五处原错图的CG像素核对及五路线逻辑验证继承0.1.4，报告保留该包原摘要，不冒充全部在0.1.5重跑；旧版本完整30存档验证同样保留原摘要。维护者实机通过反馈不等于穷举全部剧情或固件，没有测量实机峰值内存或帧率。图片解码像素不变，不等于整个渲染器绝无额外内存变化。

## 从公开源码构建

预转换 `src/` 可直接构建，无需原游戏目录。安装Node.js/npm、Python及Pillow、fontTools、cryptography；按README使用兼容aiot-toolkit 1.1.0。重新构建会因目录、编译模块ID、时间及签名元数据产生不同摘要，Release安装包始终保留维护者实测文件。

完整离线转换和版本对比脚本需要自己的原游戏副本、FreeMote、GARbro、中间图像、历史安装包或本地SDK；不能仅凭公开源码宣称已经重新进行原文或实机验证。`make-atri-only.py` 使用原0.1.3与原始中间图生成轻量资源，`portrait_layout.py` 保持当前显示几何，`align-portraits.py` 可从0.1.4几何生成0.1.5修复。安装包、原始归档、SDK、模拟器磁盘、工作检查点、私人联系方式、凭据与私钥不进入源码仓库。
