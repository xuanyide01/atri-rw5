# 开发与验证记录

维护者：xuanyide。资源分析、转换工具和运行时实现由Codex完成；实机测试与发布决定由维护者完成。

## 转换原理

从维护者提供的Steam版本提取XP3中的剧本和图像，离线恢复SCN文本、PBD角色层及TLG图片。34份剧本转换为83个场景节点，保留12,172条中文文本、三处选择及结局条件。运行时按需加载小块剧情，避免常驻完整Windows脚本引擎。演出中的镜头、粒子与视频转为静态画面；音频不包含在安装包中。主CG完整显示在上方，人物立绘按原图层深度与透明度组合，并与下方对白区域衔接。

菜单的下一章执行必要状态变化，遇选项即停，不跨过攻略判断。TRUE END按原作好、坏结局标志解锁。标题不提供章节预览，EXIT使用标准应用退出接口。30个存档栏位采用独立持久键，图标和字体修订没有改变这些键或剧情节点。

## 从公开源码构建

仓库包含已经转换的 `src/`，构建手表包无需Windows原游戏目录。准备Node.js/npm和Python，并安装Python依赖Pillow、fontTools、cryptography，然后按README构建。兼容工具锁在 `tools/compat-toolkit/package-lock.json`；`WATCH_COMPAT_TOOLKIT`可指定已安装的aiot-toolkit 1.1.0。重新构建可能因构建时间等元数据产生不同签名摘要，安装时以本次已实机测试的Release附件为准。

完整资源转换需维护者自己的原游戏副本、FreeMote、GARbro及相应中间目录；这些外部工具、原始归档、SDK和模拟器磁盘不在仓库中。离线转换脚本、历史安装修订检查和原生模拟器自动化脚本为维护流程参考，部分需要原图、中间资源、旧包或本地SDK环境，不能仅凭公开源码宣称已经重复执行了原文/实机验证。预生成字体与封面可以直接用于构建，不必重新转换素材。
